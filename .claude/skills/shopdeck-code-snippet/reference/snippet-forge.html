      What the audit checks
      
      
      Templates satisfy these by construction. Claude is told the same rules, and the audit re-checks its output — treat a red row as a real defect, not a formality.
      
      
        
        
      • 01Markup, then <style>, then <script> — one self-contained paste, in that order.
        • 
        
      • 02Every class carries your prefix. Nothing global is touched.
        • 
        
      • 03Zero external scripts or stylesheets. Fonts come from stacks already on the device.
        • 
        
      • 04Full-bleed via width:100vw; margin-left:calc(50% - 50vw) so the band escapes the theme container.
        • 
        
      • 05Mobile-first with one min-width breakpoint. No separate mobile blob.
        • 
        
      • 06prefers-reduced-motion: reduce kills the motion and leaves the content readable.
        • 
        
      • 07Text is never parked at opacity:0 waiting on an observer — a JS failure must show content, not a blank band.
        • 
        
      • 08Guarded IIFE: if (!root) return, own root only, and a data- flag so a double paste can't double-bind.
